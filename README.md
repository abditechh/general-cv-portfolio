## Edit and maintain

Edit portfolio text in `index.html` and design in `styles.css`. Edit the CV HTML files in `cv/`, or use their **Text bearbeiten / Edit text** buttons. **HTML speichern / Save HTML** downloads an updated file; replace the corresponding source file before uploading changes to GitHub.

Keep dates, employment, notice period and ongoing courses current. For each application, highlight relevant experience and explain your interest in the new role without claiming qualifications you have not earned.

The drone footage shows personal practice. Data analysis and the Google IT Support certificate are learning in progress.

## Export a CV as PDF

Open the appropriate CV page and choose **Drucken / PDF** or **Print / PDF**. Save as PDF using A4 paper, 100% scale and disabled browser headers and footers. Check the **Portfolio** hyperlink in the exported PDF before sending it; it points to the public website.

## Local preview

Open `index.html` in a browser, or serve this repository folder with VS Code Live Server. Start from this project folder so the portfolio, assets and CVs share one server root.

## Hosting

GitHub Pages publishes the `main` branch from the repository root. The website uses static HTML and CSS and needs no build or package installation. The public URLs above become available once GitHub Pages has deployed the repository.
